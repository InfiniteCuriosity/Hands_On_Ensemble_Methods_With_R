4.5 How to set up the data set so the analysis is much easier to perform

Let’s set this up to work with virtually ANY data set, not just Boston Housing. We’ll do that in two steps:

  1. Rename the target column as ‘y’

  2. Always move the target column to the right most position

These two steps will make it much easier to do our analysis using different modeling methods.

The big secret at this point is to format all the data sets in the same layout. Not just the Boston Housing data set, but the other data sets we will use, too. The last column will always be the target column, and always named ‘y’. These simple changes will speed up the coding and analysis process when we use a range of modeling methods, as you will see in just a moment.

4.7 How to set up the data to be randomly resampled

This section is going to start with our randomized data set, and then re-randomize it over and over. We’ll randomly resample it 5 times in our example.

The big picture here is that we’re going to randomize the rows, then randomly resample a certain number of times (for example, 5 times). All we are doing here is setting the data up to be analyzed. Our next step will analyze the data after each resampling, save those results, and then return the mean.

for (i in 1:5) {
  df <- df[sample(nrow(df)), ]
}

4.8 How to split data into train and test sets

We’ll use 60% train and 40% test, but those numbers are arbitrary. You may use values that work best for you.

We will start with the entire randomized data set. We will set the first 60% as the training set, and the remaining 40% as the test set.

We will be building our models on the training set, and making predictions on the test (holdout) set in the next section. We will also take a quick look at the train and test sets.

Steps to building individual models in a consistent way:

We are going to follow the same steps we used for the Boston Housing data set, except that several of the columns are factors.

  1. What does the really customer want?

This is an insurance data set, the customer wants to model the charges (the seventh column). Specifically, they want to model the charges in a way that minimizes the charges they will pay, and meet their business obligations.
