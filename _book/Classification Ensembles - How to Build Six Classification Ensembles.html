8 Building ensembles of classification models

In this section we will be building two ensembles of classification models. We will use six individual classification models, and six ensembles, for a total of 12 results.

8.0.1 Let’s start at the end and work backwards

We know we want to finish with predictions from an ensemble of classification models. Therefore we need an ensemble of classification models. Therefore we need classification models. Let’s choose five classification models for our individual models, and use same five for our ensemble. Note you may use any modeling method you wish for the ensemble, since it’s data.

Our final result will look something like this:

Let’s come up with a list of five classification models we will use:

Bagged Random Forest

C50

Ranger

Support Vector Machines

XGBoost

Note that there is nothing special about using five models. Any number of models may be used, but this set will be a very good start.

There is also nothing special about these five classification models. For your work you may use these models or any other classification models that work for you.

One point I want to know is how much time each model takes to run. Therefore we will also add a mean duration by model to the finished report.

Why add a duration report?

One of the best ways to solve data science problems is to start with a small data set, as we will do here. It can happen that one (or more) of the models will take much more time than other models. That’s easy to fix once we know the mean duration of each report.

The goal is to have an error-free set of models that will run in as little time as possible.

Since we have our basic outline, and we know where we want to end, we are ready to begin.
